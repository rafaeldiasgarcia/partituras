# atualizar-docs

## Objetivo

Lembrar que mudanças relevantes precisam atualizar a documentação do projeto.

## Quando revisar documentação

Atualizar docs quando houver mudanças em:
- arquitetura
- API
- banco
- Docker
- Flyway
- testes
- decisões técnicas

## Referências do projeto

Consultar conforme o tipo de mudança:
- `docs/architecture.md`
- `docs/api-contract.md`
- `docs/decisions.md`
- `docs/test-strategy.md`
- `README.md`
- `AGENTS.md`

## Observação

Até o momento, este arquivo funciona como documentação de apoio para uso no OpenCode/Rocket. Não foi detectado neste repositório um mecanismo local comprovado de carregamento automático dessas skills.
